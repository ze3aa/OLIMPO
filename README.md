# OLIMPO

**Autor:** Sebastian Orlando Ramos Gonzalez

Sitio web de un gimnasio que permite consultar horarios, comparar planes (HERCULES, POSEIDON y ZEUS) y solicitar inscripción o reserva en línea.

## Problemática
Los usuarios no pueden ver horarios ni inscribirse sin llamar o ir al gimnasio.

## Promociones
- Primer mes gratis en cualquier plan
- Estudiantes: mitad de precio siempre

## Funcionalidades
- Menú responsivo (hamburguesa en móvil)
- Planes en tarjetas, con selección directa hacia el formulario
- Horarios por día con botón «Reservar» que precarga el mensaje
- Galería con visor ampliado
- Preguntas frecuentes desplegables
- Formulario con validación

## Estructura
```
index.html
css/styles.css
js/script.js
img/
evidencias/   (capturas en PC, tableta y móvil)
```

## Tecnologías
HTML5 semántico, CSS3 (Flexbox, Grid, Media Queries), JavaScript, Google Fonts.

## Cómo ejecutarlo
Abre `index.html` en el navegador.
